# 🛡️ Кібербезпека для своїх — Школа ГО «Українська валькірія»

Інтерактивна сторінка-лекція (Модуль 1, **Лекції 1.2 + 1.3**) для учасниць школи.
Розрахована на **90 хвилин** живого заняття, але працює і для самостійного проходження.

**🌐 Онлайн-сторінка:** після ввімкнення GitHub Pages буде доступна за адресою
`https://<ваш-username>.github.io/valkyrie-cyber-school/`

## Що всередині

- **Лекція 1.2 — Фішинг, deepfake, шкідливі посилання**
  - ознаки шахрайського листа (терміновість, «виграш», прохання даних);
  - перевірка посилань: реальна адреса, скорочені лінки, підроблені домени;
  - deepfake і фейкові акаунти: як виглядають і як перевірити;
  - реальні схеми шахрайства проти ВПО («виплати ООН», «Нова пошта», «Дія»);
  - практика «фішинг чи ні» — розбір 4 реальних повідомлень.
- **Лекція 1.3 — OSINT-гігієна**
  - що про вас видно публічно (пошук імені, фото, телефону);
  - налаштування приватності в соцмережах;
  - геодані і фото (EXIF, фон) — особливо важливо для ВПО.
- **📋 Артефакт:** інтерактивний особистий **security-checklist** (паролі, 2FA, приватність, месенджери) — прогрес зберігається у браузері, можна роздрукувати/зберегти в PDF.
- **🎮 Гра-симулятор «Інбокс під вогнем»** — 8 раундів «фішинг чи безпечно».
- **🎯 Домашнє завдання** та **📚 перелік перевірених джерел** і інструментів (усі лінки активні).

## Технічно

- Один самодостатній файл `index.html` (HTML + CSS + JS, без збірки й залежностей).
- Темна «кібер»-тема, адаптивна верстка, друк чек-листа через `Ctrl/Cmd + P`.
- Прогрес чек-листа й рекорд гри — у `localStorage` браузера користувача.

## Як увімкнути GitHub Pages

1. **Settings** репозиторію → **Pages**.
2. **Source:** *Deploy from a branch* → гілка `main`, папка `/ (root)`.
3. **Save**. За 1–2 хвилини сторінка з'явиться за посиланням вище.
